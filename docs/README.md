# Documentation

These files are the historical planning and release record of the project that
was one repository until 2026-09-21. They are kept as written and are not
maintained.

Most of them describe the **email half**. That code lives in
[`ianzepp/vivi-mail`](https://github.com/ianzepp/vivi-mail) now, so read these as
the record of how it was planned and built, not as documentation of the tool
you have in front of you. A reader looking for how email works should start at
that repository's README.

The `release-v*.md` files cover the whole project through v9.4.0, including this
repository's own lineage, which is why they stay here. Releases from v10.0.0
onward are documented per repository.

Current documentation for this repository:

- [`../README.md`](../README.md) — the mailspace reference
- [`../AGENTS.md`](../AGENTS.md) — agent and contributor guide
- [`../skills/vivi/SKILL.md`](../skills/vivi/SKILL.md) — agent-facing CLI guidance

- [`vivi-mind-quickstart.md`](vivi-mind-quickstart.md) — standing that spike up on one box from a fresh clone
